# Machine Learning — Practice & Implementations

This repository contains my hands-on implementations and practice notebooks covering the fundamentals and advanced concepts of **Machine Learning and Data Analysis** using Python.

It reflects structured learning, experimentation, and applied understanding of core ML techniques.

---

## 📂 Repository Structure

- **ML_Codes/**  
  Core Machine Learning implementations and concept-wise notebooks.

- **Datasets/**  
  Public and practice datasets used for training, evaluation, and experimentation.

- **pca.ipynb, ICA_Basic.ipynb**  
  Dimensionality reduction and signal processing related experiments.

- Logistic Regression

- Model Evaluation & ROC Analysis
